# Hydration Strategies (激活策略)

该文件 `hydrationStrategies.ts` 定义了 Vue 3 中异步组件的懒加载激活（Lazy Hydration）策略。这些策略允许开发者控制组件何时进行客户端激活（hydration），从而优化应用的加载性能和交互体验。

## 核心概念

### `HydrationStrategy` (类型)
这是一个函数类型，接受两个参数：
1.  `hydrate`: 一个回调函数，调用它会触发组件的实际激活过程。
2.  `forEachElement`: 一个辅助函数，用于遍历组件未激活 DOM 的根元素（处理了 Fragment 的情况）。

该函数返回一个清理函数（teardown function）或 `void`。清理函数用于在组件激活前被卸载时清理副作用（如事件监听器）。

## 提供的策略

### 1. `hydrateOnIdle`
**策略**：当浏览器空闲时进行激活。
- **实现**：利用 `requestIdleCallback` API。
- **参数**：`timeout` (默认 10000ms)，指定超时时间，确保在超时后强制执行。
- **适用场景**：非关键内容的低优先级加载。

### 2. `hydrateOnVisible`
**策略**：当组件元素进入视口（可见）时进行激活。
- **实现**：利用 `IntersectionObserver` API。
- **逻辑**：
    - 首先检查元素当前是否已经在视口中（`elementIsVisibleInViewport`）。如果是，立即激活。
    - 如果不在视口中，使用 `IntersectionObserver` 监听。一旦元素进入视口，断开观察并激活。
- **适用场景**：首屏不可见的内容，如页面底部的列表、模态框内容等。

### 3. `hydrateOnMediaQuery`
**策略**：当指定的媒体查询匹配时进行激活。
- **实现**：利用 `matchMedia` API。
- **逻辑**：
    - 检查媒体查询是否当前匹配。如果匹配，立即激活。
    - 如果不匹配，监听 `change` 事件，一旦匹配则激活。
- **适用场景**：特定屏幕尺寸下才显示的组件（如移动端侧边栏）。

### 4. `hydrateOnInteraction`
**策略**：当用户与组件元素交互时进行激活。
- **实现**：监听指定的 DOM 事件（如 `click`, `mouseover` 等）。
- **逻辑**：
    - 为组件根元素添加一次性事件监听器。
    - 当事件触发时：
        1. 移除所有监听器。
        2. 执行 `hydrate()` 激活组件。
        3. **关键点**：激活完成后，重新分发（replay）该事件，确保用户的交互行为（如点击按钮）在组件激活后能被 Vue 的事件处理程序正确捕获和执行。
- **适用场景**：需要用户主动触发的功能区域。

## 辅助函数

### `forEachElement`
这是一个用于遍历 DOM 结构的辅助函数，专门处理 Vue 的 Fragment 结构。
- **逻辑**：
    - 如果节点是普通元素，直接回调。
    - 如果节点是 Fragment 的开始标记（注释节点 `[`），则遍历其兄弟节点直到找到对应的结束标记（注释节点 `]`），并处理嵌套的 Fragment。
- **作用**：确保策略能够正确地应用到组件的所有根节点上，即使组件有多个根节点（Fragment）。
