# vOn.ts 文件总结

该文件主要实现了 Vue 3 中 `v-on` 指令在 DOM 运行时的事件修饰符（Event Modifiers）和按键修饰符（Key Modifiers）的底层逻辑。它提供了对各类事件进行拦截和包装的高阶函数，以支持模板中如 `@click.stop.prevent` 或 `@keyup.enter` 的语法糖。

## 核心功能分析

### 1. 事件修饰符（`withModifiers`）
- **修饰符守卫 (`modifierGuards`)**：这是一个对象字典，预设了所有事件相关的系统及特殊修饰符拦截逻辑（如 `stop`, `prevent`, `self`, `ctrl`, `shift`, `left`, `right`, `exact` 等）。其函数如果返回 `true`，意味着修饰符条件不满足或已被拦截。
- **高阶包装**：`withModifiers` 函数接收一个原始的事件处理器 `fn` 和修饰符列表 `modifiers`。它生成一个包裹函数，在事件触发时依次执行修饰符守卫，如果任何修饰符被拦截，则提前返回且不执行原 `fn`。
- **缓存优化**：利用原函数上的 `_withMods` 属性作为缓存，相同函数及其相同修饰符组合的包装器只被创建一次，节省内存开销。

### 2. 按键修饰符（`withKeys`）
- **兼容映射表 (`keyNames`)**：维护了特定的按键别名（如 `esc` 到 `escape`，`up` 到 `arrow-up` 等），兼顾 Vue 2 遗留下的部分按键名映射。
- **高阶包装**：`withKeys` 函数接收按键事件处理器 `fn` 和修饰符列表。通过检测事件对象的 `event.key` （会转为连字符格式）是否与修饰符匹配来决定是否执行原函数。
- **Vue 2.x 兼容性 (`__COMPAT__`)**：
  - 如果应用在兼容模式下运行，则会处理已被废弃的 `keyCode` 的支持（如 `@keyup.13`）。
  - 支持了 Vue 2 时代的 `config.keyCodes` 自定义按键码全局配置。
- **缓存优化**：与 `withModifiers` 类似，通过 `_withKeys` 对象将结果缓存起来，避免重复生成封装函数。

## 总结
该文件是 Vue 3 渲染阶段处理 DOM 事件修饰符的核心模块。它通过优雅的高阶函数包装和缓存机制，将我们在模板层面编写的一长串`.stop.prevent.enter`修饰符抽象为了高效的运行时校验逻辑，并且很好地支持了向上兼容 Vue 2 版本。
